## 二、分阶段开发日志

### 阶段一：初始版 V1.0（单页小程序）

- 单页 `index.html` 实现印尼语学习卡片、发音播放

## 三、技术架构演进要点

| 维度 | 演进 |
|---|---|
| 存储 | 纯本地 → localStorage 双写 → Cloudflare KV（配置/留言/广播） + D1（用户/学习记录/排行榜） |
| 后端 | 静态页 → Cloudflare Pages Functions（文件路由 + `_shared` 共享路由表） |
| 认证 | 本地密码 → JWT（UTF-8 安全） + 心跳踢线 + 多设备控制 |
| 前端 | 单文件 → 模块化（app.js / module-study / module-challenge / module-study-practice） |
| 缓存 | 版本参数 + SW 缓存 + commitHash 自动检测刷新 |
| 视觉 | 深色科技风 → 古堡立体风 → BOSS 电影化 → 便利贴/霓虹组件 |
