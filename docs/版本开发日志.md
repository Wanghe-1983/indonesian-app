## 版本编号规则

本文档采用**统一的语义化版本号**（自 V1.0 起单调递增），与代码内历史版本号无关：



| 规则          | 说明                      | 示例                                                     |
| ----------- | ----------------------- | ------------------------------------------------------ |
| 主版本 +1（X.0） | 能力体系级升级：引入全新架构 / 全新功能体系 | 纯前端 → 云端后端（V2.0）；引入 BOSS 游戏体系（V3.0）；社交 + 游戏化完整上线（V4.0） |
| 次版本 +1（X.Y） | 功能集升级：一批新功能或全面视觉 / 交互重构 | 工号账号体系（V2.1）；边框系统重构（V3.1）                              |
| 补丁（X.Y.Z）   | 单点 BUG 修复、小优化           | 练习数据修复（V3.4）                                           |

> 代码内 
>
> `config.js`

## 技术架构演进要点



| 维度 | 演进                                                                        |
| -- | ------------------------------------------------------------------------- |
| 存储 | 纯本地 → localStorage 双写 → Cloudflare KV（配置 / 留言 / 广播） + D1（用户 / 学习记录 / 排行榜） |
| 后端 | 静态页 → Cloudflare Pages Functions（文件路由 + `_shared` 共享路由表）                  |
| 认证 | 本地密码 → JWT（UTF-8 安全） + 心跳踢线 + 多设备控制                                       |
| 前端 | 单文件 → 模块化（app.js/module-study /module-challenge/module-study-practice）    |
| 缓存 | 版本参数 + SW 缓存 + commitHash 自动检测刷新                                          |
| 视觉 | 深色科技风 → BOSS 电影化 → 古堡立体风 → 便利贴 / 霓虹组件                                     |
