## 1. 产品简介

**印尼语学习助手** 是一套面向印尼工作/生活场景的 BIPA（印尼语）学习平台，采用"学练结合 + 游戏化闯关"设计，适合工厂/公司员工从零学习印尼语。

| 项目 | 说明 |
|---|---|
| 访问方式 | 浏览器打开线上地址，或本地运行 `python -m http.server 8888` 后访问 `localhost:8888` |
| 核心模块 | 勤学苦练（学）、闯天关（玩）、留言墙（互动）、排行榜（比拼） |
| 数据存储 | 云端共享（Cloudflare KV/D1）+ 本地缓存双保险，离线可用 |
| 支持设备 | 电脑 / 手机 / 平板（PWA，可添加到主屏幕） |

## 2. 账号体系

### 2.1 三种身份

| 身份 | 说明 | 权限 |
|---|---|---|
| 注册用户 | 用**工号**注册、登录 | 全部学习/闯关/留言/排行榜功能 |
| 访客 | 无需注册，一键体验 | 仅可学习部分课程，**不能闯天关**，有时长限制（默认 3 分钟） |
| 管理员 | 系统最高权限 | 用户端全部功能 + 后台管理 |

### 2.2 注册（员工账号）

1. 在登录页切换到「注册」标签
2. 填写：**公司代码**、**工号**（纯数字，即登录账号）、**昵称**
3. 点击「注册账号」，成功后自动回到登录页

> 说明：管理员可在后台开启/关闭"员工工号验证"——开启后，工号必须存在于后台员工名单中才能注册；也可关闭自助注册，由管理员统一创建账号。

### 2.3 登录

- 输入工号 + 密码，点击「立即登录」
- 登录成功后，页面右上角显示「欢迎 + 佩戴称号 + 昵称」，并自动推送一条**欢迎登录播报**
- 登录页实时显示当前在线人数 / 注册人数（管理员可控制是否显示）

### 2.4 账号管理

- **退出登录**：右上角用户菜单 → 退出
- **修改密码 / 昵称**：用户菜单 → 个人资料
- **删除账号**：用户菜单 → 注销账号（需确认）

## 4. 勤学苦练

进入「勤学苦练」后有三个子页签：**课程** / **学习** / **练习**。

### 4.1 课程

- 按等级列出课程（当前内置：**生词 Vocabulary**、**短语 Phrases** 两大课程）
- 每个课程下有多个单元（Lesson），进入后开始学习
- 课程显示受后台「课程等级控制」约束（可学习 / 仅展示 / 隐藏），管理员可为"已登录用户"和"访客"分别设置

### 4.2 学习

- 卡片式学习：印尼语 + 中文释义逐卡展示，支持**前后翻卡**
- **发音**：点击喇叭图标播放标准发音（Google TTS）
- **倍速调节**：0.5x ~ 2.0x 语速滑块（后台可控制开关）
- **循环播放**：设置单卡循环次数（后台可控制开关）
- **收藏**：❤️ 收藏生词/短语，可随时查看收藏夹
- **已掌握标记**：勾选「已掌握」后该词进入练习题库
- **学习即记录**：**每学习一个生词/短语都会自动记录**——
  - 计入「今日学习记录」（`fmi_today_record`）
  - 计入「累计已掌握词汇」（`fmi_all_words`），作为练习模块"仅包含已掌握词汇"的题库来源
- 学习进度自动同步云端，换设备不丢

### 4.3 练习

- **题库范围**（后台可配置，用户也可选择）：
  - 仅包含已掌握词汇
  - 包含当前课本全部内容
  - 全部词汇
- **题型**：选择题、填空题（按词条类型自动匹配干扰项）
- **错题集**：答错自动加入；可删除单条 / 清空（后台控制）
- **掌握标记管理**：练习中可勾选/取消"已掌握"（后台可禁止取消）
- **学习统计**：学习时长、练习准确率自动统计

> ⚠️ 常见提示「当前已掌握词汇中只有 1 道题可练，至少需要 4 道」——说明你勾选"仅包含已掌握词汇"时，已掌握数量不足。解决：继续在「学习」页学习更多内容（学习即自动计入已掌握），或取消勾选该选项使用更大题库。

### 4.4 打卡分享

学习/练习后可生成**分享卡片**（文字或图片），分享学习成果到社交平台。

## 5. 闯天关

游戏化闯关模块，包含**闯关**和**排行榜**两个子页签。

### 5.1 两种模式

| 模式 | 说明 |
|---|---|
| 普通模式 | 常规闯关答题，**无 BOSS**，适合日常练习 |
| 地狱模式 | 高难度闯关，每等级末尾有 **BOSS 守关**，击败可得称号与边框 |

进入地狱模式时可选择**英雄性别**（男/女），战斗中展示对应英雄形象。

### 5.2 关卡地图

- 按**等级分组**展示，顶部有**通关进度条**
- 每关显示：星级（1-3星）、当前状态（未解锁/可挑战/已通关）
- 普通关卡 + **小 BOSS**（等级内每隔 N 关出现）+ **大 BOSS**（等级末尾）
- 关卡卡片可**切换列数**（后台可配置布局）

### 5.3 答题玩法

- 题型：选择题 / 填空题，题目与干扰项按类型智能匹配
- 后台可配置：闯关顺序（顺序/自由）、题目顺序（顺序/随机）、限时答题、语速、循环播放
- 地狱模式额外支持：阅卷方式（即时/交卷）、允许跳题、允许返回修改、题号导航条、**准确率淘汰线**（低于阈值强制结算）

### 5.4 BOSS 战（地狱模式）

8 个守关 BOSS，取材印尼神话/史诗（哇扬皮影戏、摩诃婆罗多、罗摩衍那、爪哇民间传说）：

| 等级 | BOSS | 出处 | 技能 |
|---|---|---|---|
| 0 | Buta Cakil 查基尔 | 哇扬皮影戏 | 木棒重击 / 盾牌格挡 / 野猪冲撞 |
| 1 | Raksasa Terong 特龙 | 爪哇民间传说 | 三叉戟突刺 / 暗影藤蔓 / 咆哮震慑 |
| 2 | Duryodhana 杜尤达纳 | 摩诃婆罗多 | 金权杖制裁 / 王盾反击 / 王权威压 |
| 3 | Kumbhakarna 库巴卡那 | 罗摩衍那 | 巨锤粉碎 / 泰山压顶 / 吞噬咆哮 |
| 4 | Sengkuni 森古尼 | 摩诃婆罗多 | 毒匕突袭 / 诡计陷阱 / 连环扇击 |
| 5 | Indrajit 因陀罗吉 | 罗摩衍那 | 幻术迷境 / 双刀乱舞 / 暗翼冲击 / 魔雾吞噬 |
| 6 | Batara Kala 堕神 | 爪哇神话 | 锯齿劈斩 / 链锤横扫 / 日轮陨落 / 毁灭咆哮 |
| 7 | Kalabendu 混沌王 | 哇扬皮影戏原创 | 万魔斩 / 混沌诅咒 / 灵魂吞噬 / 业火焚天 / 虚空裂隙 |

BOSS 战特色：
- **血条系统**：BOSS 与英雄双血条，BOSS 按等级显示火焰/橙色/黄色分级特效
- **技能动画**：BOSS 技能名发光展示、攻击特效、降临炸裂动画、粒子效果
- **战斗机制**：BOSS 弹药倍数、暴怒 / 最后一搏机制、HP 模式（按题量/自定义）
- **BOSS 图鉴**：可查看每个 BOSS 的故事背景、招式列表
- 击败 BOSS 掉落：**专属称号** + **专属关卡边框**；大 BOSS 首杀计入**首杀榜**，解锁首杀称号

### 5.5 结算

通关后按准确率/用时评分（最高 3 星），成绩写入排行榜；地狱模式胜利/失败均有专属结算页（含 BOSS 处决动画效果）。

## 6. 称号系统

- **解锁**：地狱模式击败大 BOSS 即解锁对应称号（如「混沌王首杀」），并**立即装配可选**
- **称号墙**：在闯天关-称号墙查看全部已获得称号
- **佩戴/卸下**：点击称号即可佩戴，再次点击卸下
- **展示**：佩戴后，主页右上角显示「欢迎 + 称号 + 昵称」，例如：`欢迎 混沌王首杀 大熊`
- 称号数据本地保存 + 云端同步（`user/titles/equip`）

## 7. 关卡边框系统

- **解锁**：每击败一个 BOSS 获得一款专属边框（共 8 款），边框**角落带 BOSS 出处徽记**，证明边框来自哪个 BOSS
- **专属配色**：每款边框有专属层级颜色（翡翠 / 紫晶 / 琥珀金 / 橙焰 / 暗紫 / 赤红 / 烈焰 / 极光幻彩）
- **特效**：流光扫光、发光、旋转光束等动画
- **装备/卸下**：
  - 关卡边框页 → 选择边框 → **装配到当前关卡**（每关专配唯一性，一关一款）
  - **批量装备**：一键装配全部解锁边框到对应关卡
  - **卸下全部**：一键清空所有关卡的边框
- 装备后关卡卡片显示该边框装饰

## 8. 排行榜

### 8.1 普通模式排行榜（周/月/总榜）

- 页签切换：**本周 / 本月 / 总榜**
- 顶部展示**周冠军横幅**（上周冠军 + 总积分）
- 榜单显示：排名（前三带皇冠）、昵称、公司、积分；自己的排名高亮

### 8.2 地狱模式排行榜（多分支）

| 分支 | 规则 |
|---|---|
| 🏆 首杀榜 | 8 个 BOSS 按层级排列，**大 BOSS 首杀**入榜，仅保留每个 BOSS 的首杀记录 |
| 🔥 高分榜 | 各关卡最高分排序 |
| ⚡ 速通榜 | 各关卡最快通关时间排序 |
| 🏁 全通榜 | 地狱模式通关进度（通关数/总数、总积分、总星数、完成率） |

> 说明：普通模式榜单为云端共享；地狱模式本地多分支榜以本机数据为准（多设备登录请以云端提交记录为准）。

## 9. 留言墙

- **入口**：主页「留言墙」功能卡
- **风格**：便利贴 + 图钉，四色（黄/粉/蓝/绿）瀑布流错落展示
- **发布**：填写「写给谁」（昵称/所有人）、署名（留空用昵称）、内容（≤200字）
- **公开/私密**：
  - 勾选「公开留言（所有人可见）」→ 显示「致 XX」
  - 取消勾选 → 私密留言（🔒 标识），仅本人和管理员可见
- **展示顺序**：最新在前（时间倒序）+ 瀑布流多列（宽屏 3 列 / 平板 2 列 / 手机 1 列）
- **删除**：本人或管理员可删除自己的留言
- **存储**：云端共享（部署后所有人可见同一面墙）；离线自动回退本地存储，功能不中断

## 10. 广播（小喇叭）

- 登录播报开关、默认欢迎词

## 13. 常见问题

**Q1：练习提示"题目不足/已掌握词汇只有 1 道题可练"？**
A：勾选"仅包含已掌握词汇"时题库=已掌握词汇，数量不足 4 道无法开始。到「学习」页继续学习新内容（每个学过的词自动计入已掌握），或取消勾选用更大题库。

**Q2：访客为什么不能闯天关？**
A：默认访客仅开放学习功能；管理员可在「访客设置」中开启"允许访客闯天关"。

**Q3：换了设备数据还在吗？**
A：注册用户的勤学苦练进度、已掌握词汇会云端同步；留言墙云端共享；本地数据（边框装配、本地排行）跟随设备。

**Q4：为什么页面提示刷新？**
A：检测到新版本部署，刷新即可加载最新功能。

**Q5：忘记密码？**
A：联系管理员在「注册用户管理」中重置。

**Q6：如何修改后台管理密码？**
